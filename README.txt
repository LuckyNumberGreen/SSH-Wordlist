SSH Brute-forcer (ssh_brute.py)

Prerequisites:
Python 3 with Paramiko installed
A text file containing passwords (e.g., passwords.txt) in the same directory

The format expected by the password txt file can be copied from the example txt includeds
How to Run:
python3 ssh_brute.py

Prompts during runtime:
1. Target IP address (e.g., Metasploitable2 IP)
2. Username (msfadmin)
3. Password file name (passwords.txt)
